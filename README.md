# 📘 ECON 121 — Principles of Macroeconomics

**Interactive Self-Learning Edition**  
University of Malakand · BS Economics · 1st Semester

A single-file interactive study guide for ECON 121. Covers 3 chapters, 16 topics, and includes teacher-integrated notes, real-life examples, and mini-quizzes with instant feedback — all in pure HTML/CSS/JS, no frameworks.

## ✨ Features

- **Progress Tracker** — Animated ring + top progress bar. Mark topics as done and watch your completion percentage update live.
- **Mini-Quizzes** — Every topic ends with an interactive checkpoint. Instant correct/wrong feedback with explanations.
- **Teacher Notes Integrated** — Key exam points, definitions, and 5-assumption lists from lecture notes baked in.
- **Sticky Sidebar Navigation** — Jump to any topic. Active topic auto-highlights as you scroll.
- **Scroll Animations** — Topics fade in on scroll using the Intersection Observer API.
- **Dark Theme** — Easy on the eyes for long study sessions.
- **Fully Responsive** — Works on desktop and mobile.

## 📖 How to Use

1. Open the page in any browser.
2. Read through each topic in order, or jump to any section via the sidebar.
3. Click **✓** on a topic once you feel confident with it — your progress ring updates automatically.
4. Answer the quiz at the bottom of each topic to test yourself.
5. Use the sticky top bar to track your overall completion percentage.

> Progress resets on page refresh (no backend). This is by design — it's a study tool, not a grade tracker.
